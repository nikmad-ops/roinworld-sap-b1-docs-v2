## Шаблоны Пользовательских интерфейсов
Каждый объект SAP Business One содержит множество полей. Часть имеющихся в Системе полей скрыта по причине их нерелевантности процессам Roin World. 
В рамках внедрения SAP создан набор Пользовательских интерфейсов (UI), содержащий информацию о том, какие поля необходимо отображать пользователям.
Настройка набора UI относится к компетенции администратора и не может быть выполнена конечным пользователем так как затрагивает всех пользователей Системы.
При этом, конечным пользователям доступна настройка собственного представления интерфейса. Внесённые изменения остаются на уровне пользователя и не затрагивают других участников Системы. 

## NB
1. Набор доступных к настройке полей зависит от типа объекта. Для документов и отчётов доступный список ограничен ядром SAP. 
2. Настройка полей в Пользовательских отчётах (отчёты из Менеджера запросов) через настройку формы невозможна. Если в Пользовательский отчёт необходимо добавить какое-то поле - обратитесь к администратору. 
3. Наличие поля в списке доступных не гарантирует наличие в данном поле значений.
4. Любые настройки выполняются на свой страх и риск и должны быть обоснованы.
5. Инструмент настройки полей имеет свои особенности и в некоторых случаях он способен отметить видимыми большее количество полей. Это известное поведение Системы которое может иметь или не иметь место в конкретной версии SAP клиента.
6. Все вносимые пользовательские настройки гарантировано сохраняются только если в конце рабочего дня пользователь выходит из SAP через верхнее меню Файл -> Выход. Сохранение при закрытии клиента кнопкой [Х] не гарантируется.  

## Настройка интерфейса
Пользовательская настройка выполняется для каждой отдельной формы. 
Для настройки видимости и порядка отображения полей необходимо:
1. Открыть форму, которую необходимо настроить
2. При сфокусированной форме нажать кнопку [Параметры настройки формы], расположенную на Панели инструментов.

   <img width="333" height="95" alt="image" src="https://github.com/user-attachments/assets/e8b2a206-b9c0-4b16-a4ef-82d6ce09acc2" />

3. В открывшемся окне перейти на вкладку 'Формат таблицы'

   <img width="549" height="333" alt="image" src="https://github.com/user-attachments/assets/6608af71-12d0-421c-8fdb-bae61b9cb215" />

4. На данной вкладке показан список всех доступных для настройки полей
   (1) Настройка видимости поля
   (2) Настройка активности поля (регулирует возможность ввода значения в поле)
   (3) Направление очерёдности отображения полей. Самое верхняя позиция будет показана первой слева, позиции ниже - по очерёдности слева направо. 
   <img width="427" height="682" alt="image" src="https://github.com/user-attachments/assets/841c9830-10ff-4633-a0aa-07680b2da281" />

5. Устанавливая отметки напротив каждого из полей в колонке 'Видимость' настроить какие поля будут показаны.
6. При необходимости изменить сортировку полей 
 6.1. Нажать и держать левую кнопку мыши в строке с полем
 6.2. Дождаться появления чёрной рамки вокруг названия поля
 <img width="316" height="76" alt="image" src="https://github.com/user-attachments/assets/1978a294-eeda-4b61-a157-a99ddc79f63e" />

 6.3. Удерживая кнопку мыши нажатой переместить строку, установив её  в необходимый порядок
 6.4. Отпустить кнопку мыши

7. Закончив внесение изменений нажать кнопку [ОК]
Настройка формы завершена.
