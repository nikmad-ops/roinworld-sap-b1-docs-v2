# Учёт денежных средств, выданных подотчётным лицам

Выдача денежных средств отражается в SAP проводкой Бухгалтерской операции.

## Выдача денежных средств

Для отражения выдачи необходимо выполнить следующие шаги: 

1. Из Главного меню отрыть -> Финансы -> Бухгалтерская операция

<img width="310" height="185" alt="image" src="https://github.com/user-attachments/assets/78da471c-de08-4ee8-ba24-7c67620f1237" />

2. Заполнить заголовок Бухгалтерской операции, указав 

<img width="1355" height="331" alt="image" src="https://github.com/user-attachments/assets/dfa6d30d-0610-4811-9d28-259564ba29cf" />
  (1) Дату проводки. (2) Дату исполнения - крайний срок предоставления отчёта по выданной сумме. (3) Примечание - текстовое определение оперции, которое будет   
  видимо в отчётах. (4) В поле Подотчётное лицо нажать на символ лупы и в открывшемся окне выбрать из списка получателя денежных средств


3. Перейти к заполнению строчной части Операции. Обратите внимание, что заполнение отмеченных ниже полей является равнозначным. 

<img width="1195" height="331" alt="image" src="https://github.com/user-attachments/assets/65365a68-ba6b-4c4d-b937-750042e2b27e" />

4. Заполнить таблицу следующим образом:

<img width="1682" height="303" alt="image" src="https://github.com/user-attachments/assets/d298dc22-ce32-41ca-92ce-41014430626f" />

(1) Проверить, что подотчётное лицо установлено в строках. (2) Для кредитовой строки установить Статью ДДС 'Выдача наличных средств подотчётному лицу'
(3) Для корреспонденции использовать счёт 'Custody'

5. (АКТУАЛЬНО ДЛЯ ПРОДУКТИВНОЙ БАЗЫ) Перейти на вкладку 'Вложения' и приложить первичный документ

<img width="1815" height="129" alt="image" src="https://github.com/user-attachments/assets/5451f450-2860-4a0d-b58f-2f62700b256c" />

## Зачёт средств ранее выданных подотчётному лицу

1. Открыть Бухгалтерскую операцию и заполнить Заголовок

<img width="1038" height="144" alt="image" src="https://github.com/user-attachments/assets/f1981eb4-2bbd-40de-afcc-af94108bf048" />

2. Перейти к заполнению табличной части. При этом:
Для счёта по кредиту указать статью ДДС 'Зачёт средств ранее выданных подотчётному лицу'
Для ввода Бизнес-партнёра, чей документ планируется закрыть зачётом установить курсор в поле 'Счёт ГК\БП' и нажать комбинацию клавиш [Ctrl]+[Tab]. Эта комбинация откроет список бизнес партнёров. 

<img width="725" height="77" alt="image" src="https://github.com/user-attachments/assets/64ee39ce-c805-40f2-b008-5c2d108e64ee" />

3. Проверить что все поля заполнены корректно

<img width="1680" height="302" alt="image" src="https://github.com/user-attachments/assets/27e4b2ae-73ad-4ca6-8972-8f29379e7120" />

4. Нажать кнопку [Добавить] для выполнения проводки

5. (АКТУАЛЬНО ДЛЯ ПРОДУКТИВНОЙ БАЗЫ) Перейти на вкладку 'Вложения' и приложить первичный документ

6. Выполнить Выверку созданной операции с соответствующим документом (Закупка).
