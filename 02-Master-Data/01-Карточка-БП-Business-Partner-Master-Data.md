Инструкция будет обновлена по результатам теста (после определения минимального набора полей для карточки БП)

Для создания карточки для нового бизнес партнёра (БП), необходимо:
1. Удостовериться, что необходимый БП не был ранее создан
2. Создать карточку БП в Справочнике бизнес партнёров

## Проверка сущестования БП
Для проверки наличия в системе карточки БП необходимо
1. Открыть Справочник Бизнес партнёров из Главного меню -> Бизнес партнёры -> Справочник бизнес партнёров
<img width="394" height="204" alt="image" src="https://github.com/user-attachments/assets/50c6b993-ed9f-4c3f-8e50-e96828dd0aaf" />

2. SAP откроет справочник БП.
3. Удостовериться, что справочник открыт в режиме Поиска (поля окрашены в жёлтый цвет)
   Если поля белые - переключить форму в режим поиска, нажав на кнопку Поиск, расположенную на панели инструментов или комбинацию клавиш [Ctrl]+[F]
    <img width="543" height="262" alt="image" src="https://github.com/user-attachments/assets/246ebfee-d6ee-4b6f-9fb6-76245f2d8010" />

   
4. Ввести известный реквизит проверяемого БП. Например TaxID или название 
   При этом необходимо использовать символ * (звездочка) для маскировки неизвестной части
   Например Tax ID 123456 вводится в поле Код в формате   * 123456 *   (без пробелов) 
   Или название Muhammad Mahmoud Muhammad Shahwi вводится в формате  * Muhammad * (без пробелов)
   <img width="423" height="133" alt="image" src="https://github.com/user-attachments/assets/435635c8-82b9-4b70-8714-5ddc2789c1d7" />

5. Нажать кнопку [Поиск] расположенную в нижней части формы
6. Если в системе существует несколько БП удовлетворяющих условиям, то будет открыт список подходящих БП. 
   Если в системе только один удовлетворяющий БП то будет открыта его карточка
   Если в системе нет удовлетворяющих записей, то будет выдана ошибка
   <img width="703" height="36" alt="image" src="https://github.com/user-attachments/assets/53422e45-b7f4-48c7-b011-19809de1a001" />


## Создание карточки бизнес партнёра
1. Для создания карточки БП необходимо переключить режим формы справочника в режим Создания
   Для этого необходимо нажать кнопку Добавить расположенную на панели инструментов, или нажать комбинацию клавиш [Ctrl]+[A]
   <img width="449" height="248" alt="image" src="https://github.com/user-attachments/assets/dbc3d6c0-baf6-46f5-9212-47d80f8291e5" />

2. В карточке находящейся в режиме добавления новой записи (белые поля) заполнить следующий МИНИМАЛЬНЫЙ набор полей
   <img width="435" height="198" alt="image" src="https://github.com/user-attachments/assets/2f5f2d31-3c6a-45ae-8b7f-2506ddc8ad08" />

   
   (1) Код - TAX Id бизнес партнёра (с префиксом страны резиденства в формате ISO 2 digit. Для египетских резидентов это EG)
   (2) Тип БП - Поставщик или Клиент
   (3) Название - Название бизнес партнёра латиницей
       Название на ин.языке - Название бизнес партнёра на арабском (при наличии)
   (4) Группа БП - соответствующая роли БП
   (5) Валюта - валюта в которой будут создаваться документы. Важно, после проводки первого документа смена валюты невозможна
   (6) ИНН - Tax Id без префикса

3. Перейти к заполнению вкладки Условия оплаты
<img width="594" height="213" alt="image" src="https://github.com/user-attachments/assets/8c718f83-a6fa-4d1f-9fe2-21dd0dc171ac" />

Выбрать условия опалаты и прайс лист, который будет применён при создании документов

4. Перейти к заполнению вкладки Финансы
   На вкладке Налог указать применимый налог
   <img width="814" height="163" alt="image" src="https://github.com/user-attachments/assets/fd3865cf-8719-44cb-a9ea-07f643cb8a60" />

5. При необходимости использовать Withholding tax, на вкладке Налог установить отметку "Подлежит уплате НИД" 
   и перейти к выбру применимых ставок WHT :
   <img width="751" height="306" alt="image" src="https://github.com/user-attachments/assets/09c1d376-64c2-4b80-8a99-5fd629adfb22" />

   
6. По окончании ввода нажать кнопку [Добавить] для сохранения карточки БП
