# Инвентаризация | Inventory Counting

### Вводная информация
Инвентаризация подразделяется:

**По основанию проведения:**

**Обязательная** — проводится в случаях, предусмотренных законом и стандартами учёта (например, перед годовой отчётностью, при смене материально ответственного лица, реорганизации или ликвидации).

**Инициативная** — проводится по решению руководства или собственников для внутреннего контроля, поиска неликвида или оценки сохранности имущества. 

**По охвату:**

**Сплошная** — охватывает все активы (товары) находящиеся на всех складах. 

**Выборочная** — затрагивает только конкретный склад, категорию товаров, или часть позиций.

## NB 
1. Решение о проведении Инвентаризации принимается Главным Бухгалтером Компании. 
2. Инвентаризация не является способом пополнить\уменьшить складской остаток товара на складе. Для этих целей необходиио использовать документ Поступление товара (Goods Receipt) и Списание (Goods Issue).
3. SAP позволяет проводить инвентаризацию с привлечением двух и более лиц а также групп. Технически, в Системе это добавит в таблицу подсчёта доплонительные колонки для ввода посчитанных количеств для каждого из участников и вкладку для группы. В рамках данной инструкции групповая инвентаризация не рассматривается. 
Принцип инвентаризации и внесения остатков остаётся аналогичным индивидуальной инвентаризации. 

## Общие рекомендации 

Общими рекомендациями по проведению инвентаризации являются:
1. Перед началом инвентаризации убедиться, что все товарные движения занесены в Систему.
2. Заморозка складских операций на время проведения подсчёта. 
3. Проведение подсчёта по каждому из складов отдельно (одна Ведомость - один склад).

## Создание Ведомости 
Ведомость - документ, содержащий информацию о текущем остатке на указанном в строке складе. Также, в рамках этого документа фиксируется подсчитанное количество товара. Ведомость отражает количество товара, актуальную на дату, указанную в Заголовке документа. Процесс создания ведомости заключается в выборе\добавлении товаров которые необходимо подсчитать. 
Для создания Инвентаризационной ведомости необходимо выполнить следующие шаги:

1. Из Главного меню открыть пункт Запасы -> Операции по скаду -> Операции учёта товарных запасок -> Учёт товарных запасов. 

<img width="426" height="270" alt="image" src="https://github.com/user-attachments/assets/1ee24770-75b7-4167-a7b0-df29cd743455" />

2. Инвентаризационная ведомость будет открыта в режиме Создание новой записи.

Последовательно заполнить Заголовок (1), и только после этого перейти к заполнению Табличной части (2)

<img width="1258" height="752" alt="image" src="https://github.com/user-attachments/assets/1410b767-d767-4036-9ed7-3cdd775fcff8" />

3. Ввести данные Заголовке:

(1) Дата подсчёта - дата проведения подсчёта. Эта дата будет использована Системой для калькуляции текущего количества товаров на складе.

(2) Тип инвентаризации - установить 'Отдельный инвентаризатор'.

(3) Инвентаризатор - указать ответственного за подсчёт.
