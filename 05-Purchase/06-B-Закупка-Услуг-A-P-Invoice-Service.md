# Закупка услуг
Закупка услуг рассматривается на примере закупки услуг по контракту, с автоматическим формированием инвойсов на ежемесячной основе. При этом, технически обязательным элементом из описания ниже является документ Закупка.

## Особенности
Документ Закупка с использованием S-товара не требует наличия базового документа. Другими словами - Закупка может быть создана без предварительных документов Заказ на закупку и Поступление.

## Этапы
1. Создание шаблона для документа Закупка (опц.)
2. Создание Договора
3. Утверждение Договора
4. Обработка периодических операций

## Договор
Договор в SAP может иметь Товарный или Денежный тип, он может настроен на периодическую генерацию связанных документов или без неё.

### Типы Договора
Товарный - Договор определяет поставку оговоренных товаров, по согласованной цене в рамках установленного периода действия.
Денежный - Рамочный Договор определяет поставку неопределённого списка товаров в рамках согласованной суммы в рамках установленного периода.

### Статус Договора
Черновик - статус при котором возможно редактирование всех полей формы. Договор не может быть использован в документах.
Утверждено - редактирование полей запрещено. Договор может быть использован в документах.
Приостановлено - часть полей доступна для редактирования. Договор не может быть использован в документах.
Завершено - действие Договора завершено. Договор не может быть использован в документах.

(2) Номер договора 
(3) Метод договора - Денежный

## Утверждение Договора

1. Когда Договор с Поставщиком подписан, необходимо изменить его статус на вкладке 'Общее' с 'Черновик' на 'Утверждено'

2. После изменения статуса, необходимо внести его номер в черновик (шаблон Закупки). Только в этом случае Закупка будет привязана к Договору!
   Для этого :

4. Открыть утверждённый Договор, перейти на вкладку 'Периодические операции' и оттуда через шаблон перейти к черновику
